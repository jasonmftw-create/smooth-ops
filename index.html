Add to home screen

Android · Chrome

  1. Open this HTML file in Chrome.
  2. Tap the ⋮ menu.
  3. Choose Add to Home screen or Install app.
  4. Confirm the name and tap Add.

iPhone · Safari

  1. Open this HTML file in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.

Keep using the same browser. Clearing that browser's site data removes local entries, so make a backup first.

Backup & restore

What the backup is for

Your entries live only in this browser on this device. A backup is a small JSON file that protects your data if you clear browser storage, change phones, or move to a newer SMOOTH-OPS HTML file.

Export a backup

  1. Tap Export backup.
  2. Save the JSON file in Downloads, Files, or another safe place.
  3. When moving to an update, export from the old file before opening the new one.

Re-import a backup

  1. Open the new SMOOTH-OPS HTML file in Chrome or Safari.
  2. Return here and tap Restore backup.
  3. Choose the SMOOTH-OPS JSON file from Downloads or Files.
  4. Confirm the restore. Your stores, visits, notes, hours and settings will reappear.
